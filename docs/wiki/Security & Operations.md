# JonesPride Profile — Security & Operations

## Repository purpose
This repository is a public-facing profile document. Its primary operational risks are inaccurate claims, broken links, and accidental publication of private contact details or credentials.

## Controls
- Never include API keys, access tokens, passwords, or private repository URLs containing secrets.
- Review personal contact and employment details before publication.
- Keep technical claims traceable to project documentation and test evidence.
- Do not copy private project configuration into the public profile.
